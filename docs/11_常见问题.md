# 11 常见问题

## 页面相关

**Q：双击 `index.html` 为什么空白？**
页面用 `fetch` 读取 `data/*.json`，`file://` 会被浏览器拦截。必须用本地 HTTP：

```powershell
python -m http.server 8766 --bind 127.0.0.1 --directory delivery/materials_kg_final
```

**Q：端口被占用？**
换端口：`--port 8771`，浏览器访问对应地址。

**Q：页面打开很慢？**
首屏加载 8 个 JSON（节点 22 MB、边 39,400 条）；浏览器首次解析需要几秒。后续证据按论文懒加载。

**Q：中文搜索不到？**
中文只覆盖 57 个高频概念建议标签；其余用英文规范名、缩写或化学式搜索。

**Q：为什么同一篇论文的关系在图上分散在不同区域？**
区域按“概念类型”划分；关系跨区域，这是正常的跨层连接。社区色块表示关系聚类，不改变类型区域。

## 数据相关

**Q：三元组在哪？**
交付包根目录 `triples_full.csv` / `triples_full.jsonl`；规范化源在 `evaluation/full_v3_delivery/relations.jsonl`。

**Q：为什么关系数比“原始三元组”少？**
70,802 条原始记录包含观测（16,829）和数值事实（12,649）；关系候选 41,324 条去重后进入 39,400 条规范关系。

**Q：为什么同一个说法在 18 篇论文里是 18 条边？**
设计如此：每条边保留 `paper_id` 和证据，便于追溯；不把论文级声明合并成“共识”。

**Q：`not reported` 是什么？**
v2 的“属性未报告”标记，不是真正的语义关系；342 条，清理时应单列。

**Q：为什么有些关系没有行号？**
原文定位失败（1,475 条，3.7%）；页面会标注“定位缺失”，不伪造行号。

## 抽取相关

**Q：`LLMTruncatedError` 怎么办？**
提高 `max_tokens`（材料项目建议 ≥16000）或减小 `chunk_size`；推理模型要留足隐藏推理预算。

**Q：`401/403`？**
`api_key` 未设置或错误；推荐 `api_key = "env:DEEPSEEK_API_KEY"` 并先 `$env:DEEPSEEK_API_KEY="..."`。

**Q：`429` / 连接超时？**
降低 `concurrency`（如 8→3），提高 `max_retries`，检查端点。

**Q：能断点续跑吗？**
可以。`extract_corpus.py` 默认跳过已有 `raw`/`enriched`；`--force` 强制重跑单篇。

**Q：缓存会泄露内容吗？**
`.kg-cache` 保存请求与回复；交付包不包含该目录。清理可直接删除。

## 交付相关

**Q：ZIP 解压后还需要 Python 吗？**
不需要。页面是纯静态文件 + 本地 HTTP 服务；CSV/JSONL 可直接用 Excel/Pandas。

**Q：怎么校验包没坏？**
`python article/export_materials_graph.py --verify-only --output-dir <解压目录>`，应为 15/15。

**Q：能导入 Gephi 吗？**
交付包含 `materials_kg.gexf`；导出时加 `--gexf`。

**Q：能改图里的颜色/标签吗？**
颜色由 `data/meta.json` 的类型色和 `communities.json` 的社区色决定；标签在 `materials_overview.js` 的 `paintLabel` 部分。

## 开发相关

**Q：改了 JS 怎么检查？**
`node --check src/knowledge_graph/templates/materials_overview.js`，再导出包刷新页面。

**Q：改了 Python 怎么回归？**
`python -m pytest tests -q`，并跑一次 `--verify-only`。

**Q：为什么测试里有 skipped？**
缺少 FastAPI/uvicorn 时，服务器测试跳过；安装 `.[web]` 后消失。
