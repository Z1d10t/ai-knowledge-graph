# 02 快速开始

## 1. 环境要求

| 项 | 要求 |
|---|---|
| Python | 3.11 及以上（开发用 3.12） |
| 必需依赖 | `jinja2`、`networkx`、`requests` |
| 可选依赖 | `fastapi`、`uvicorn`、`python-multipart`（Web 界面）、`pypdf`、`python-docx` |
| 浏览器 | Chrome / Edge / Firefox 任一现代浏览器 |
| LLM | 任意 OpenAI 兼容的 `/chat/completions` 端点（只有重新抽取时需要） |

查看当前环境：

```powershell
python scripts/check_env.py
```

## 2. 安装

### 方式 A：pip（推荐给只读代码/跑页面）

```powershell
cd ai-knowledge-graph-main
python -m pip install -e ".[dev,web]"
```

### 方式 B：uv

```powershell
uv sync --extra dev --extra web
```

### 方式 C：不安装，直接跑

```powershell
$env:PYTHONPATH = "src"
python -m pytest tests -q
```

仓库根目录的 `generate-graph.py` 等价于 `python -m knowledge_graph.main`，不安装也能跑。

## 3. 先跑测试（不需要 LLM）

```powershell
python -m pytest tests -q
# 期望：167 passed, 1 skipped（不同环境可能略有差异）
```

或：

```powershell
powershell -ExecutionPolicy Bypass -File scripts/run_tests.ps1
```

## 4. 跑两篇论文的示例（不需要 LLM、不需要全量数据）

示例已经放在 `examples/`，也可以从全量数据重建：

```powershell
python scripts/build_mini_example.py
python article/export_materials_graph.py `
  --input-dir examples/mini_v3 `
  --papers-dir examples/mini_papers `
  --output-dir examples/mini_package --force
python article/export_materials_graph.py --verify-only --output-dir examples/mini_package
```

期望输出：`2` 篇论文、`52` 条关系、`95` 个概念、`4` 个实例；校验 `11/11`。

打开示例页面：

```powershell
python -m http.server 8770 --bind 127.0.0.1 --directory examples/mini_package
# 浏览器访问 http://127.0.0.1:8770/
```

## 5. 打开完整交付页面

```powershell
python -m http.server 8766 --bind 127.0.0.1 --directory delivery/materials_kg_final
# 浏览器访问 http://127.0.0.1:8766/
```

- 首页 = 全库大图（12 个类型区域 + 社区斑块）。
- 右上角「EN / 中文」切换界面语言；也可用 `?lang=en`。
- 搜索 `ALD`、`4Cl-BZS`、`AgBiS2`、`甲酸根` 可直接进术语邻域。
- 「下载三元组」下载 `triples_full.csv`；「导出 PNG」导出当前视图。

若没有 `delivery/materials_kg_final/`，先解压 `delivery/materials_kg_v3.1-delivery.zip`。

## 6. 用 LLM 生成一张新图

1. 复制示例配置并填入模型信息：

```powershell
Copy-Item configs/config.materials.example.toml my-config.toml
# 编辑 my-config.toml：model / base_url / api_key（建议 api_key = "env:DEEPSEEK_API_KEY"）
$env:DEEPSEEK_API_KEY = "..."
```

2. 运行：

```powershell
python -m knowledge_graph.main `
  --config my-config.toml `
  --input path\to\paper.md `
  --output out\paper.html `
  --export json,csv,graphml,cypher
```

输出：

- `out/paper.html`：自包含交互页；
- `out/paper.json`：三元组；
- 可选 `paper.csv` / `paper.graphml` / `paper.cypher`。

3. 只从已有 JSON 重绘页面（不调用模型）：

```powershell
python -m knowledge_graph.main --from-json out/paper.json --output out/paper2.html
```

## 7. 配置要点

完整键说明见 `docs/09_运行手册.md` 和 `src/knowledge_graph/config.py` 的 `DEFAULTS`。

材料项目最关键的四项：

```toml
[profile]
name = "materials"        # 12 类材料实体；关闭 LLM 推断

[llm]
model = "deepseek-flash"
base_url = "https://api.deepseek.com/chat/completions"
api_key = "env:DEEPSEEK_API_KEY"
max_tokens = 16000
concurrency = 8

[chunking]
chunk_size = 450
overlap = 60

[inference]
enabled = true
use_llm_for_inference = false
taxonomy = false
llm_bridge = false
llm_hub = false
```

## 8. Windows 注意事项

- PowerShell 里多行命令用反引号 `` ` `` 续行。
- 路径含中文/空格时加引号。
- 不要用 `file://` 直接打开页面：页面用 `fetch` 读 `data/`，必须走 HTTP。
- 端口被占用时换一个，例如 `--port 8771`。
- 终端编码建议 `$env:PYTHONIOENCODING = "utf-8"`。
