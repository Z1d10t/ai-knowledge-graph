# 08 评估与交付脚本

本目录脚本分三类：**规范化**（v2 → v3）、**质量评估**（参考集/指标）、**交付构建**（导出包/汇报包）。

## 1. 规范化：`evaluation/normalize_v3.py`

**输入**

- `evaluation/full_v2/kg_output/enriched/*.json`：285 篇 v2 抽取结果。
- `evaluation/targeted_reextract_v3/*.json`：12 个定向补抽文件（`terms` + `triples`）。
- `../材料论文/全部_285篇/md`：论文 Markdown，用于定位行号。

**处理**

1. 逐篇注册概念：中心词拆分、化学式身份、复数、缩写（按论文）、已知同义词。
2. 识别论文内实例（device A / sample 3），生成 `i-...`。
3. 关系去重：同论文同主语/谓词/宾语/极性合并，保留全部证据。
4. 定向补抽：校验术语在正文出现 → 接受/并入/拒绝，记录 `term_ingest_log.json`。
5. 观测：把 `obs-` 属性边与 owner 边（材料 → has measurement → obs）合并，恢复 value/unit/sample/conditions。
6. 数值事实、中文建议标签、类型冲突、方向检查、别名索引。

**输出**

```
concepts.jsonl           instances.jsonl        mentions.jsonl
relations.jsonl          relations_raw.jsonl    observations.jsonl
numeric_facts.jsonl      alias_index.json       id_map.json
type_conflicts.json      type_unresolved.json   fixes_applied.json
term_ingest_log.json     stats.json             manifest.json
```

**CLI**

```powershell
python evaluation/normalize_v3.py --output-dir evaluation/full_v3_delivery
python evaluation/normalize_v3.py --limit 3 --output-dir evaluation/smoke_v3   # 冒烟
python evaluation/normalize_v3.py --papers 001,250 --output-dir evaluation/two_v3
```

**计数**：概念 51,464、实例 920、关系 39,400、观测 16,829、数值事实 12,649。

## 2. 定向补抽：`evaluation/targeted_reextract.py`

- 读取 v2 结果 + 参考术语/关系，找出“该有但没抽到”的段落。
- 合并行区间为优先段落，调用 LLM 抽 `terms` 与 `triples`，逐条校验引文是否命中正文。
- 输出到 `evaluation/targeted_reextract_v3/<paper>.json`，含 `terms`、`triples`、`summary`。

```powershell
python evaluation/targeted_reextract.py --dry-run
python evaluation/targeted_reextract.py --workers 3
python evaluation/targeted_reextract.py --papers 001,007 --force
```

结果：12 个文件、340 条可用三元组、674 条术语条目。

## 4. 交付导出：`article/export_materials_graph.py`

**职责**：把 v3 规范层变成可浏览、可下载、可移交的包。

```powershell
python article/export_materials_graph.py `
  --input-dir evaluation/full_v3_delivery `
  --papers-dir "../材料论文/全部_285篇/md" `
  --output-dir delivery/materials_kg_final `
  --version v3.1-delivery `
  --bundle-papers --gexf --force
```

| 参数 | 说明 |
|---|---|
| `--input-dir` | v3 目录 |
| `--papers-dir` | 论文 md 目录（证据分片 + 打包） |
| `--output-dir` | 输出包 |
| `--version` | 版本标签 |
| `--bundle-papers` | 把 md 原文复制进包内 `papers/` |
| `--gexf` | 额外生成 Gephi 文件 |
| `--force` | 覆盖已有输出 |
| `--verify-only` | 只校验已有包 |
| `--attach-png` | 用页面截图替换总览 PNG |

**构建步骤**

1. `load_graph()`：读入并校验 ID 唯一、端点存在、实例有论文作用域。
2. `build_nodes()`：概念 + 实例 → 节点。
3. `layout_communities()`：Louvain 社区 → 12 个类型圆盘 → 社区斑块 → 固定坐标。
4. `build_triples()`：关系 → 18 列三元组。
5. `build_evidence()`：按论文生成证据分片，复制原文。
6. `write_browser_data()`：`data/*.json`、`search.json`、`communities.json`。
7. `write_page()`：模板 + vis-network 资源。
8. `render_overview_png()`：Pillow 生成占位总览图（可被页面截图替换）。
9. `verify()`：15 项检查。

**15 项检查**

1. 必需文件存在
2. CSV 18 列
3. CSV 行数 = manifest 关系数
4. JSONL 行数 = manifest 关系数
5. 唯一 `relation_id` 数 = JSONL 行数
6. 节点数一致
7. 端点可解析（缺失 0）
8. 论文覆盖数一致
9. 证据分片数一致
10–14. 术语检索：ALD、4Cl-BZS、AgBiS2、甲酸根、α/δ-FAPbI3 不混并
15. 文件哈希与 manifest 一致

小数据集（<1000 条关系）会跳过第 10–14 项并标注原因。
