# 06 数据模型

本文说明三层数据（v2 抽取、v3 规范、交付包）的字段、计数口径和完整性规则。

## 1. v2 抽取层

位置：`evaluation/full_v2/kg_output/enriched/<paper_id>.json`（每篇一个数组）。

一条三元组：

| 字段 | 说明 |
|---|---|
| `subject` / `predicate` / `object` | 原文语义三元组 |
| `subject_type` / `object_type` | 模型给出的实体类型（materials profile 下为 13 类之一） |
| `source` | 证据句（模型从原文摘录） |
| `chunk` | 该句所在块号 |
| `value` / `unit` / `conditions` / `sample_id` / `device_id` | 数值、单位、条件、样品/器件 |
| `value_type` / `source_study` / `condition_status` | 测量类型、是否转引、条件来源 |
| `evidence_level` / `section` / `page` / `table_id` | 可选出处信息 |
| `origin` | extracted / inferred / observation / ontology |

materials profile 的 13 类：material、material_class、sample、structure、device、process、condition、property、measurement、characterization、mechanism、defect、interface。

## 2. v3 规范层

位置：`evaluation/full_v3_delivery/`。所有文件均为 UTF-8 JSONL（除 JSON 索引）。

### 2.1 `concepts.jsonl` — 概念（51,464）

| 字段 | 说明 |
|---|---|
| `concept_id` | `c-<sha1>` 稳定 ID |
| `canonical_name` | 规范名 |
| `type` / `type_status` / `type_reason` | 12 类之一；consistent / conflict_resolved / v2_fallback / type_pending |
| `formula` / `identity` | 化学式与跨论文身份键 |
| `quality` | clean / fragment / instrument / symbol |
| `aliases` | 别名记录：`alias`、`scope`（global/paper）、`paper_id`、`kind`、`verified`、`evidence` |
| `surface_forms` | `{表面形式: 次数}` |
| `papers` / `paper_count` / `mention_count` | 来源论文与计数 |
| `v2_types` / `conflicts` | 观察到的类型与冲突 |
| `language_labels` | `{en, zh_suggested}` |
| `source` / `review_status` | 来源与复核状态 |

### 2.2 `instances.jsonl` — 论文内实例（920）

| 字段 | 说明 |
|---|---|
| `instance_id` | `i-<sha1(paper|label)>`，按论文隔离 |
| `paper_id` | 所属论文 |
| `label` / `type` | 原文标签与类型（多为 sample/device） |
| `linked_concept_id` | 若能对应到概念则填 |
| `evidence` | 出处句 |

### 2.3 `mentions.jsonl` — 提及（145,881）

| 字段 | 说明 |
|---|---|
| `paper_id` / `v2_index` / `chunk` | 来源定位 |
| `role` / `mention_kind` | concept / instance / observation / value / symbol |
| `surface` | 正文写法 |
| `concept_id` / `concept_name` / `concept_type` | 指向的概念 |
| `attributes` | 属性短语拆分结果（head/qualifiers） |
| `evidence` / `evidence_line` | 证据句与行号 |

### 2.4 `relations.jsonl` — 规范关系（39,400）

| 字段 | 说明 |
|---|---|
| `relation_id` | `r-<sha1>`，计数单位 |
| `paper_id` / `chunk` / `v2_index` | 来源 |
| `subject_id` / `object_id` | 概念或实例 ID |
| `subject_kind` / `object_kind` | concept / instance |
| `subject_label` / `object_label` | 规范名 |
| `subject_type` / `object_type` | 12 类 |
| `predicate` / `raw_predicate` / `family` | 规范谓词、原谓词、谓词族 |
| `evidence` / `evidence_line` / `evidence_level` | 引文、行号、证据级别 |
| `evidence_text_match` | 引文是否逐字命中正文 |
| `polarity` / `modality` | positive/negative；asserted/hedged |
| `direction_ok` / `direction_issue` | 方向是否合理及原因 |
| `scope` / `source` / `review_status` | 作用域、来源、复核 |
| `evidence_all` / `v2_indices` / `duplicate_count` | 合并后的全部证据、原始索引、重复数 |

### 2.5 `observations.jsonl` — 观测（16,829）

| 字段 | 说明 |
|---|---|
| `observation_id` | `obs-...` |
| `paper_id` | 所属论文 |
| `property_concept_id` / `property` | 测的是什么属性 |
| `value` / `value_raw` / `unit` / `comparator` / `range` / `uncertainty` | 数值信息 |
| `value_type` | measured / reported / derived |
| `conditions` / `condition_status` | 条件列表与来源 |
| `sample_id` / `source_study` | 样品与转引研究 |
| `owner_label` / `owner_type` / `owner_concept_id` | 测量所属材料/器件 |
| `evidence` / `evidence_owner` / `evidence_line` | 两段证据 |

### 2.6 `numeric_facts.jsonl` — 数值事实（12,649）

未进入关系图的数值表达：`paper_id`、`subject`、`predicate`、`value`、`unit`、`property`、`sample_id`、`conditions`、`evidence`、`evidence_line`。

### 2.7 索引与元数据

| 文件 | 内容 |
|---|---|
| `alias_index.json` | 归一化键 → 别名条目（concept_id、alias、kind、scope、paper_id、verified） |
| `id_map.json` | 论文标签 → 概念、v2 边 → relation_id、实例 → 概念 |
| `type_conflicts.json` | 类型冲突队列 |
| `type_unresolved.json` | 类型回退/待定 |
| `fixes_applied.json` | 应用过的修规则 |
| `term_ingest_log.json` | 定向补抽术语的接受/合并/拒绝日志 |
| `stats.json` | 全量统计（概念、关系、观测、方向、别名等） |
| `manifest.json` | 输入文件 SHA-256、版本、计数 |

## 3. 交付包

位置：`delivery/materials_kg_final/`。

### 3.1 `triples_full.csv` — 18 列

```
relation_id, subject_id, subject, predicate, object_id, object,
subject_type, object_type, family, paper_id, evidence_line, evidence,
evidence_text_match, direction_ok, polarity, modality, review_status, source
```

- UTF-8 BOM，Excel 直接打开。
- 39,400 行 + 1 行表头。
- JSONL 额外字段：`duplicate_count`、`subject_kind`、`object_kind`。

### 3.2 `nodes.jsonl` — 节点（52,384）

| 字段 | 说明 |
|---|---|
| `node_id` | 概念/实例 ID |
| `kind` | concept / instance |
| `label` / `type` / `quality` | 名称、类型、质量 |
| `paper_count` / `mention_count` / `papers` | 跨论文信息 |
| `aliases` / `surface_forms` / `zh` | 别名、表面形式、中文建议 |
| `formula` / `linked_concept_id` | 化学式 / 实例关联概念 |
| `community` | 社区编号（-1 表示未着色） |
| `degree` / `in_graph` / `x` / `y` | 度数、是否在关系图、坐标 |

### 3.3 `data/` — 页面数据

| 文件 | 形状 |
|---|---|
| `meta.json` | 版本、生成时间、计数、类型/谓词族/谓词表、论文列表与标题 |
| `nodes.json` | 数组：`[id,label,typeIdx,quality,paperCount,mentionCount,degree,inGraph,x,y,community,zh,aliases,surfaces,paperId]` |
| `edges.json` | 数组：`[relIdx,srcIdx,tgtIdx,predIdx,famIdx,paperIdx,flags]`（flags：1=方向异常，2=无行号） |
| `relids.json` | 关系 ID 数组，`edges` 的 `relIdx` 指向它 |
| `adjacency.json` | 节点 → `[relationIdx, otherNode, direction]` |
| `overview.json` | 类型汇总：类型节点、类型间边、计数 |
| `search.json` | `{k: {归一化键: [节点下标]}}` |
| `communities.json` | `count`、`extent`、`list`（社区）、`regions`（12 类型区域）、`patches`（社区斑块） |
| `evidence/<paper_id>.json` | `relation_id → [引文, 行号, 上下文]`，按需加载 |
| `papers.json` | 论文列表与链接（如打包原文） |

### 3.4 `manifest.json`

`version`、`data_version`、`generated`、`papers`、`concepts`、`instances`、`relations`、`csv_rows`、`in_graph_nodes`、`searchable_only_nodes`、`anomalies_direction`、`no_evidence_line`、`evidence_shards`、`search_keys`、`files`（SHA-256）、`input_stats`。

## 4. 计数口径

- **全库关系** = `relations.jsonl` 中唯一 `relation_id` 数（39,400）。
- **当前筛选** = 应用类型/谓词族/论文/异常开关后的关系数。
- **当前已绘制** = 画布已画出的关系数（全图一次画完）。
- **方向异常** = `direction_ok=false`（159）。
- **无行号** = `evidence_line` 为空（1,475）。
- **证据行号覆盖** = 1 − 1,475/39,400 = 96.3%。

## 5. 完整性规则

1. `concept_id`、`instance_id`、`relation_id` 全局唯一。
2. 每条关系的 subject/object 必须能在节点层找到（导出时校验，缺失为 0）。
3. 实例必须带 `paper_id`，不跨论文共用。
4. 同一论文内相同关系（同主语/谓词/宾语/极性）合并，保留全部证据。
5. CSV 行数 = JSONL 行数 = 唯一 `relation_id` 数。
6. 交付包文件哈希写入 `manifest.json`，`--verify-only` 会逐项校验。
