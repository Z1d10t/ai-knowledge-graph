# 04 核心模块（配置、LLM、提示词、文本、主流程）

本文按“从外到内”的顺序说明每个模块的职责、关键 API 和改动注意事项。

## 1. `config.py` — 配置

**职责**：读取 TOML，填默认值，解析 `env:` 密钥，校验类型和范围。

| API | 输入 | 输出/行为 |
|---|---|---|
| `load_config(path)` | TOML 路径 | dict；文件缺失/非法时打印错误并返回 `None` |
| `apply_defaults(config)` | dict | 原地补齐 `DEFAULTS`，返回同一 dict |
| `validate_config(config)` | dict | 校验数值范围、布尔类型、URL；解析密钥；失败抛 `ConfigError` |
| `resolve_secret(value)` | `"env:NAME"` / `"${NAME}"` / 普通字符串 | 环境变量值或原值 |

`DEFAULTS` 的主要键：

| 段 | 键 | 默认 |
|---|---|---|
| `profile` | `name` / `version` | `generic` / `1.0` |
| `llm` | `max_tokens` / `temperature` / `timeout` / `max_retries` | 32768 / 0.2 / 300 / 3 |
| | `token_param` / `json_mode` / `concurrency` / `cache_dir` | `auto` / false / 4 / `.kg-cache` |
| `chunking` | `chunk_size` / `overlap` | 500 / 50 |
| `extraction` | `language` | `auto` |
| `query` | `hops` / `max_triples` / `max_seed_entities` / `use_llm_for_entity_matching` / `history_turns` | 2 / 150 / 8 / true / 3 |
| `standardization` | `enabled` / `use_llm_for_entities` / `merge_word_subsets` | true / true / false |
| `inference` | `enabled` / `use_llm_for_inference` / `taxonomy` / `llm_bridge` / `llm_hub` / `max_inferred_ratio` … | 见源码 |
| `visualization` | `edge_smooth` / `name_communities` / `theme` / `edge_labels` / `title_case` / `collapse_parallel_edges` | 见源码 |

**注意**：任何字符串都可用 `"env:VAR"` 从环境变量取密钥；配置文件不要提交真实 key。

## 2. `llm.py` — OpenAI 兼容客户端

**职责**：请求 `/chat/completions`，处理重试、截断、空回复、缓存和 JSON 提取。

| 类/函数 | 说明 |
|---|---|
| `LLMError` | 所有 LLM 错误的基类 |
| `LLMRequestError` | HTTP 失败或响应体异常 |
| `LLMTruncatedError` | `finish_reason == "length"`，说明 token 预算不够 |
| `LLMEmptyResponseError` | 模型没有可用内容 |
| `LLMResponse` | `content`、`finish_reason`、`reasoning`、`usage`、`raw`；`truncated` 属性 |
| `LLMClient` | 数据类；字段与 `[llm]` 配置一一对应 |
| `LLMClient.from_config(config)` | 从 `[llm]` 构造，解析密钥 |
| `LLMClient.complete(user, system)` | 返回文本；截断/空回复抛异常；缓存命中直接返回 |
| `LLMClient.complete_raw(...)` | 返回 `LLMResponse`，保留 usage 与原始 JSON |
| `extract_json_from_text(text, expect="array")` | 从回复中抽 JSON：去 `<think>`、代码围栏、前后散文、尾逗号、`{"triples": [...]}` 包装、截断数组修复 |
| `call_llm(...)` | 旧版一次性函数，建议改用 `LLMClient` |
| `strip_reasoning(text)` | 去掉推理模型输出的 `<think>...</think>` |

**重试**：408/409/425/429/5xx 和连接错误按指数退避重试，默认 3 次。

**token 参数**：`token_param="auto"` 时先发 `max_tokens`；若服务端报错要求 `max_completion_tokens`，客户端记住并自动切换。

**缓存**：`cache_dir` 下按（模型、prompt、参数）的 SHA-256 存 JSON；重复跑不花钱。`cache_dir=""` 或 `--no-cache` 关闭。

**注意**：材料项目把 `max_tokens` 设到 16000 以上；过小会在长块上截断，抛 `LLMTruncatedError`。

## 3. `prompts/` — 提示词

| 文件 | 内容 |
|---|---|
| `main_prompts.py` | 通用抽取提示词；`materials` 抽取提示词（12 类实体、受控谓词、数值/条件字段） |
| `entity_prompts.py` | 判断两个实体是否同一概念的提示词 |
| `inference_prompts.py` | 桥接、枢纽、社区内关系推断提示词 |
| `community_prompts.py` | 给社区起短名 |
| `query_prompts.py` | 图问答与实体选择 |

| API | 说明 |
|---|---|
| `system_prompt_for(name, config)` | 取 system prompt，并追加 `extraction.language` 指令 |
| `main_prompt_pair(config)` | 按当前 profile 返回 `(system, user)` |
| `PromptFactory.get_prompt(name)` | 按名字取模板 |
| `language_instruction(language)` | `Chinese` 等语言时追加“用该语言输出实体和谓词” |

**注意**：改提示词会改变抽取分布，必须同时更新 `evaluation/` 的冻结配置与测试基线。

## 4. `text_utils.py` — 文本处理

| API | 行为 |
|---|---|
| `split_sentences(text)` | 按段落和句末标点切句；常见缩写（e.g., Fig., et al.）不误切 |
| `chunk_words(text, size, overlap)` | 纯按词切块，可能切断句子 |
| `chunk_text(text, size, overlap)` | 按句子边界切块，目标词数 `size`，块间重叠 `overlap`；返回块列表 |
| `find_source_sentence(text, subject, object)` | 找同时提到两个实体的句子；找不到时退回只含主语的句子 |

**注意**：`chunk_text` 是抽取质量的关键；材料项目用 `450/60`，长综述可用 `500/80`。

## 5. `profiles.py` — 领域 profile

| API | 说明 |
|---|---|
| `profile_name(config)` | 当前 profile 名（默认 generic） |
| `active_profile(config)` | profile 字典 |
| `entity_types(config)` | 允许的实体类型元组 |
| `is_materials(config)` | 是否材料 profile |
| `map_predicate(predicate, config)` | 返回 `(规范谓词, 是否未映射)`；同义词先归一 |
| `apply_profile_overrides(config)` | materials 强制关闭推断相关开关 |

**generic**：9 类（person/organization/place/event/technology/product/work/date/concept），谓词自由。

**materials**：13 类（material/material_class/sample/structure/device/process/condition/property/measurement/characterization/mechanism/defect/interface），受控谓词 6 族，内置同义词（enhances→improves、grown by→deposited by 等），并强制关闭 taxonomy/lexical/LLM 推断。

## 6. `main.py` — 主流程

| 函数 | 说明 |
|---|---|
| `process_with_llm(config, text, debug, client)` | 一次 LLM 抽取：取提示词 → 请求 → 抽 JSON → 校验字段 → `normalize_triple` |
| `normalize_triple(item, chunk_text, config)` | 保留 subject/predicate/object、类型、数值/条件/样品等扩展字段；校验类型；附证据句 |
| `process_text_in_chunks(...)` | 单文本入口，内部转 `process_documents` |
| `process_documents(config, documents, debug, continue_on_error, stats)` | 切块 → 线程池抽取 → 合并 → 标准化 → 推断 → 观测 → 条件后处理；返回全部三元组 |
| `read_input_text(path)` | 多编码读取文本；二进制格式给出明确报错 |
| `collect_input_files(paths)` | 目录展开、后缀过滤、存在性校验 |
| `read_documents(paths)` | 返回 `(name, text)` 列表 |
| `load_triples_from_json(path)` | 从已生成 JSON 载入，跳过 LLM |
| `save_graph_meta/load_graph_meta` | 社区名 sidecar（`.meta.json`）读写 |
| `make_community_namer(config)` | 返回社区命名回调或 None |
| `get_unique_entities(triples)` | 去重实体集合 |
| `main()` | CLI 入口 |

CLI 主要参数：

| 参数 | 说明 |
|---|---|
| `--config` | TOML 路径 |
| `--input PATH...` | 一个或多个文件/目录 |
| `--output` | HTML 输出路径 |
| `--from-json` | 从已生成 triples JSON 重绘 |
| `--export` | `json,csv,graphml,cypher` 组合 |
| `--profile` | 覆盖配置里的 profile |
| `--no-standardize` / `--no-inference` | 关闭对应阶段 |
| `--continue-on-error` | 单块失败不中断整篇 |
| `--no-cache` | 禁用 LLM 缓存 |
| `--debug` / `--quiet` | 日志级别 |

**注意**：`process_documents` 对空回复会重试一次；仍失败时受 `continue_on_error` 控制。
