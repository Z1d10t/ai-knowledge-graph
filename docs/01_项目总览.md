# 01 项目总览

## 1. 这个项目是什么

这是一个面向材料科学的**术语知识图谱流水线 + 可交互图谱页面 + 可移交数据包**。

输入是论文 Markdown/PDF，输出是：

1. **抽取层**：LLM 从每篇论文抽出的主语—谓词—宾语三元组，带类型、原文引文和行号。
2. **规范层**：把论文里的写法合并成 51,464 个专业概念、920 个论文内实例，形成 39,400 条规范关系。
3. **页面层**：12 个类型区域的全库大图、术语邻域、类型汇总，支持搜索、筛选、悬停、证据回查和中英文切换。
4. **交付层**：三元组 CSV/JSONL、页面数据、285 篇原文、总览 PNG、清单和校验脚本。

## 3. 三层数据

```
材料论文 (.md/.pdf)
        │  generate-graph / article/extract_corpus.py（materials profile + LLM）
        ▼
v2 抽取层  evaluation/full_v2/kg_output/enriched/*.json
        │  evaluation/normalize_v3.py（概念合并、类型、别名、证据、观测）
        ▼
v3 规范层  evaluation/full_v3_delivery/
        │  concepts / instances / mentions / relations / observations / numeric_facts
        │  article/export_materials_graph.py
        ▼
交付包  delivery/materials_kg_final/
        index.html + data/ + triples_full.csv/jsonl + nodes.jsonl + PNG + papers/
```

- **v2 抽取层**：保留 LLM 原样输出，一篇论文一个 JSON，可重跑、可审计。
- **v3 规范层**：概念、实例、提及、关系、观测分文件，是页面和三元组的唯一数据源。
- **交付包**：把 v3 变成浏览器可打开、Excel 可读、可整包移交的形态。

## 5. 关键设计选择

1. **论文级声明，不造共识**：每条关系保留 `paper_id`，跨论文相同说法不合并；99.4% 的三元组只来自一篇论文。
2. **术语优先**：先解决“同一个词的不同写法”，再谈关系质量；化学式、相、缩写、复数、别名都有明确规则。
3. **证据可回查**：每条关系尽量带原文引文和行号；无行号会明确标“定位缺失”。
4. **材料 profile 关闭推断**：`profiles.py` 的 materials 模式强制关闭 LLM 关系发明、词法/分类推断，事实必须来自正文。
5. **离线页面**：不依赖 CDN，数据按论文分片，打开本地 HTTP 服务即可用。
6. **可校验交付**：导出后自动跑 15 项检查（计数、端点、证据分片、术语检索、哈希）。

## 6. 能做什么

- 输入术语/别名/缩写/中文建议标签，定位到概念、论文、关系和原文。
- 按类型、谓词族、论文、方向异常筛选全库关系。
- 从 12 个类型区域的全库大图逐层缩放到术语与单条关系。
- 导出当前视图 PNG；下载全量三元组 CSV。
- 用 `KnowledgeGraphIndex` 在自己的程序里检索、浏览概念卡、查两个概念之间的关系。
- 整包移交：解压 + 本地 HTTP 服务即可演示，无需 Python 环境。

## 7. 边界

- 不是问答系统或性能预测模型；观测数值不做跨论文排名。
- 语义准确率、召回率尚未做独立抽样评估；当前质量口径是“计数守恒、端点完整、证据可定位、可移交”。
- 已知待清：65 个规范名重复节点、159 条方向待复核、44 条自环、342 条 `not reported`、4,799 条引文未逐字命中。
