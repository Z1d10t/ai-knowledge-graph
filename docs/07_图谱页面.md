# 07 材料图谱页面（前端）

页面位于 `src/knowledge_graph/templates/`：

| 文件 | 作用 |
|---|---|
| `materials_overview.html` | 结构：页头、搜索、工具栏、侧栏、画布、详情面板、页脚 |
| `materials_overview.css` | 布局与主题：浅色卡片、侧栏、面板、导出模式 |
| `materials_overview.js` | 数据加载、四视图渲染、搜索、悬停、证据、双语、导出 |
| `vendor/vis-network.min.js/.css` | 邻域视图的图库，随包离线分发 |

导出时 `article/export_materials_graph.py` 会把三者复制为 `assets/app.html/js/css`，并写入 `data/`。

## 1. 页面结构

```
header
 ├─ 品牌（标题/副标题）
 ├─ 搜索框 + 下拉结果
 └─ 工具栏：全库大图 / 全部关系 / 类型汇总 / 下载三元组 / 导出 PNG / EN
main.workspace
 ├─ aside.sidebar
 │   ├─ 社区列表（Top 14，可点击筛选）
 │   ├─ 类型 chips（12 类，多选）
 │   ├─ 筛选：谓词族、论文、方向异常、清除
 │   └─ 图例与说明
 ├─ section.stage
 │   ├─ 统计条：全库关系 / 当前筛选 / 当前已绘制 / 视图名
 │   └─ canvas 层：graph-canvas + overlay-canvas
 │      另有 overview-canvas（类型汇总）与 #network（vis 邻域）
 └─ aside.panel（详情）
footer：数据版本、离线提示
```

## 2. 启动流程

```js
boot()
  Promise.all([
    meta.json, nodes.json, edges.json, relids.json, overview.json,
    adjacency.json, search.json, communities.json,
  ])
  → 构建 nodeColor / typeColor / 社区颜色
  → applyLanguage()
  → buildSidebar()
  → bindEvents()
  → showGraph(true)          // 全库大图
  → applyHash()              // #q= / #type= / #view= / #anomalies= / #node=
```

`?export=1` 时给 `body` 加 `export-mode` 类，隐藏页头/侧栏/面板，画布铺满窗口。

## 3. 四个视图

| 视图 | 触发 | 渲染 |
|---|---|---|
| 全库大图 | 默认 / `btn-graph` | Canvas：类型区域 + 社区斑块 + 关系网 |
| 全部关系 | `btn-full` | 同一 Canvas 渲染器，保留当前筛选 |
| 类型汇总 | `btn-type` / `#view=type` | Canvas 环图，外弧连接 12 类 |
| 术语邻域 | 搜索/双击/`#q=` | vis-network 径向布局，一跳 150 节点/300 边 |

## 4. 全库大图渲染

数据来自 v3 布局：节点有固定 `x/y`，`communities.json` 提供 12 个类型区域（`regions`）和社区斑块（`patches`）。

`renderGraph()` 顺序：

1. 用当前筛选计算 `state.filtered`（边下标）。
2. 计算 bbox 与视口 `fitView()`（负坐标要加 `-minX*scale` 偏移）。
3. 画类型区域：半透明圆 + 虚线描边。
4. 画边：按主语类型分组批量 `stroke`，颜色为该类型色、透明度 0.13。
5. 画节点：屏幕坐标圆点，半径随度数，颜色 = 社区色（前 60 社区）或类型色。
6. 画标签：区域标题 → 社区斑块 → 枢纽术语，全部做矩形碰撞避让。
7. 更新三个计数。

**屏幕坐标绘制**：不缩放 canvas 上下文，而是把世界坐标转屏幕坐标；线宽/字号保持屏幕像素，缩放时视觉稳定。

## 5. 悬停与点击

- `overlay-canvas` 独立于底图：悬停时不重绘底图，只画半透明白底 + 高亮边 + 邻居点 + 浮层。
- `nodeAt(x, y)` 用屏幕坐标数组找最近节点，阈值随缩放变化。
- 单击节点 → `selectNode()` → 右侧详情面板。
- 双击节点 → `startNeighbourhood()` → vis 邻域。
- 拖拽平移、滚轮以鼠标为中心缩放；用 `requestAnimationFrame` 合并重绘。

## 6. 搜索

`searchKey(text)` 统一大小写、希腊字母（α→alpha）、上下标、连字符、乘号；**保留 CJK 字符**。

候选分三级：

1. 精确键；
2. 前缀；
3. 子串。

结果按匹配级别 + 度数排序，最多 24 条；点击进入邻域并打开概念卡。

## 7. 详情面板

- 节点：规范名、类型、质量、中文建议、社区、论文数、关系数、提及数、别名/表面形式、出边/入边列表、三个动作（展开邻域/再展开/全库定位）。
- 关系：谓词、方向、两端类型、论文标题与编号、`relation_id`、证据框（引文/行号/上下文）、打开论文 Markdown。
- 证据按论文懒加载：`data/evidence/<paper_id>.json`，缓存在 `state.evidenceCache`。

## 8. 中英文

- `I18N` 字典分 `zh` / `en`，覆盖页头、按钮、侧栏、面板、提示、空状态。
- 类型名/谓词族名由 `meta.json` 同时提供 `label_zh` / `label_en`。
- 切换语言：`applyLanguage()` 更新静态文案，重建侧栏、重绘画布/环图、重渲染当前面板。
- 选择写入 `localStorage["materials-kg-lang"]`；`?lang=en` 可强制英文。

## 9. 哈希与参数

| 参数 | 效果 |
|---|---|
| `#q=ALD` | 搜索并进入第一个结果的邻域 |
| `#node=<node_id>` | 打开指定节点 |
| `#type=material` | 只看某个类型 |
| `#view=type` | 类型汇总 |
| `#view=full` | 全部关系 |
| `#anomalies=1` | 显示方向异常 |
| `?lang=en` | 英文界面 |
| `?export=1` | 无 UI 的导出模式 |

## 10. 导出 PNG

- 页面内「导出 PNG」：`canvas.toBlob()` 下载当前视图。
- 交付包总览图：用无头浏览器打开 `?export=1`，截 2600×1600，再由
  `export_materials_graph.py --attach-png` 写回包内并更新哈希。
- 导出模式会额外绘制标题、规模统计和底部社区图例。

## 11. 性能

- 39,400 条边 + 41,124 个节点，全库大图一次绘制约几十毫秒；平移/缩放用 rAF 合并。
- 悬停只画 overlay，不重绘底图。
- 邻域视图限制 150 节点/300 边，避免 vis 物理布局卡顿。
- 证据分片按论文加载，首屏只取 8 个数据文件。

## 12. 改页面时的注意事项

1. 节点行字段顺序必须与 `export_materials_graph.write_browser_data` 一致。
2. 新增文案要同时加 `zh`/`en` 两个键。
3. 新增画布元素要区分底图/overlay，避免悬停时全量重绘。
4. 改完 JS 用 `node --check` 做语法检查（仓库测试不覆盖 JS）。
5. 改完导出脚本后运行 `--verify-only`，确认哈希与计数仍通过。
