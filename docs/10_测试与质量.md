# 10 测试与质量

## 1. 测试怎么跑

```powershell
python -m pytest tests -q
# 或
powershell -ExecutionPolicy Bypass -File scripts/run_tests.ps1
```

当前基线：**167 passed, 1 skipped**（缺 FastAPI 时服务器测试跳过）。

只跑某个模块：

```powershell
python -m pytest tests/test_terminology.py -q
python -m pytest tests/test_retrieval.py -q
python -m pytest tests -q -k "term or alias"
```

## 3. 质量检查（交付级）

### 3.1 导出校验

```powershell
python article/export_materials_graph.py --verify-only --output-dir delivery/materials_kg_final
```

15 项：文件存在、18 列、CSV/JSONL 行数、唯一 ID、节点数、端点、论文数、证据分片、5 个术语检索、文件哈希。

### 3.2 数据不变量

- CSV 行数 = JSONL 行数 = 唯一 `relation_id` 数。
- 端点缺失 = 0。
- 每个实例都有 `paper_id`。
- 证据分片数 = 论文数。
- 包内 `manifest.json` 的 SHA-256 与实际文件一致。

### 3.3 页面验收

- 三个计数随筛选变化。
- 搜索 ALD / 4Cl-BZS / AgBiS2 / 甲酸根。
- α-FAPbI3 与 δ-FAPbI3 不混并。
- 方向异常开关：39,241 → 39,400。
- 中英文切换、PNG 导出、下载 CSV。

### 3.4 前端语法

仓库测试不覆盖 JS；改完执行：

```powershell
node --check src/knowledge_graph/templates/materials_overview.js
```

## 4. 已知缺口（不是测试失败）

- 65 个规范名存在重复节点（粒度问题）。
- 159 条方向待复核、44 条自环、342 条 `not reported`。
- 4,799 条引文未逐字命中（其中 949 条同时无行号）。
- 中文建议标签仅 57 个。

这些是数据质量队列，已在报告与页面标注，不作为“代码回归”。

## 5. 加测试的建议

1. 纯函数优先放 `test_text_utils.py` / `test_terminology.py`。
2. 涉及 LLM 的用 `fakes.FakeClient`，不要发真实请求。
3. 涉及文件系统的用 `tmp_path`。
4. 新增导出字段时，在 `test_exports.py` 或导出脚本自检里加断言。
5. 修改术语规则时，至少补一个“会合并”和“不会合并”的对照用例。
