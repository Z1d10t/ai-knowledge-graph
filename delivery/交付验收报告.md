## 3. 两项离线修复

### 3.1 挽回已抽到的术语（`normalize_v3.py --output-dir`）

- 输入：12 个定向补抽文件中的 **674** 条术语条目。
- 处理：校验术语在对应论文正文出现 → 走现有 `ConceptRegistry`（中心词、别名作用域、
  化学式/相规则）→ 记录来源行；不满足条件的不进入图谱。
- 结果：**接受 144 / 并入既有概念 477 / 拒绝 53**（48 条正文未出现、5 条为论文内实例标签）。
- 概念数 51,408 → 51,464（+56）；新增提及 621 条；逐条日志见
  [`evaluation/full_v3_delivery/term_ingest_log.json`](../evaluation/full_v3_delivery/term_ingest_log.json)。

### 3.2 恢复观测的值、单位和归属

- v2 把数值写在「材料/器件 → has measurement → obs-id」边，v3 原实现只读「obs-id → measures →
  属性」边，导致 value/unit/sample/conditions 为空。
- 修复：按 `(paper_id, observation_id)` 索引两个方向的边并组装。回归结果：

| 字段 | v2 可恢复数 | 交付版恢复数 |
|---|---:|---:|
| value | 16,334 | 16,342 |
| unit | 15,573 | 15,578 |
| sample_id | 16,789 | 16,789 |
| conditions | 6,430 | 6,446（7,971 个条件项） |
| 无主观测（owner 缺失） | — | 0 |

多出的少量数值来自属性边自带的字段。观测只放在样品/器件/属性侧栏，不作为跨论文性能排名；
数值仍属附加信息，不进入主线关系。

## 4. 页面与实现要点

- **四个视图**：全库大图（canvas，类型区域 + 社区斑块 + 三级标签）、全部关系（同一渲染器 +
  当前筛选）、类型汇总（外弧环图）、术语邻域（vis-network，一跳 150 节点/300 边，可继续展开）。
- **布局**：Louvain 社区检测 → 12 个类型圆盘按面积做向日葵式无重叠排布 → 社区在圆盘内按
  黄金角螺旋成斑块；节点坐标为确定性网格，同一输入重复导出完全一致。
- **数据**：`data/nodes.json`（15 字段数组，含社区编号）、`data/edges.json`、`data/relids.json`、
  `data/search.json`（53,598 个归一化键）、`data/adjacency.json`、`data/communities.json`
  （区域 / 社区 / 斑块）、`data/evidence/<paper>.json`（285 个分片，按需加载）。
- **检索**：ID/完整名 → 精确别名 → 前缀 → 子串；支持英文、缩写、希腊字母（α/δ）和中文建议标签；
  大小写折叠只用于候选，节点身份仍是 v3 ID；歧义别名列出多个候选。
- **交互**：悬停时在独立 overlay canvas 上高亮该节点及其邻居并显示浮层，不重绘底图；
  平移/缩放使用屏幕坐标直接绘制并按视口裁剪；标签按缩放级别分层，且做碰撞避让。
- **国际化**：界面文案集中在 `I18N` 字典，类型/谓词族标签由数据同时提供中英文；
  切换语言后侧栏、详情、图表标签即时重绘，选择写入 localStorage。
- **PNG**：`?export=1` 模式隐藏页头/筛选/侧栏，保留标题、统计与底部类型图例，
  由无头浏览器截图为 2600×1600，再通过 `--attach-png` 写回包内并更新哈希。

## 5. 复现命令

```powershell
cd ai-knowledge-graph-main

# 1) 基线交付（冻结 v3）
python article/export_materials_graph.py --input-dir evaluation/full_v3_normalized `
  --papers-dir "../材料论文/全部_285篇/md" `
  --output-dir delivery/materials_kg_baseline --version v3.0-baseline

# 2) 含两项离线修复的规范化数据
python evaluation/normalize_v3.py --output-dir evaluation/full_v3_delivery

# 3) 最终交付包
python article/export_materials_graph.py --input-dir evaluation/full_v3_delivery `
  --papers-dir "../材料论文/全部_285篇/md" `
  --output-dir delivery/materials_kg_final --version v3.1-delivery `
  --bundle-papers --gexf

# 4) 校验（任一包）
python article/export_materials_graph.py --verify-only --output-dir delivery/materials_kg_final

# 5) 本机打开
python -m http.server 8766 --bind 127.0.0.1 --directory delivery/materials_kg_final
# 浏览器打开 http://127.0.0.1:8766/
```

PNG 重新导出（可选）：打开 `http://127.0.0.1:8766/?export=1` 截图，然后
`python article/export_materials_graph.py --attach-png <png> --output-dir delivery/materials_kg_final`。

## 6. 已知限制与留待下一轮

1. **全图可读性**：39,400 条边在适配屏幕的缩放下仍很密；类型块标签与缩放/筛选可缓解，
   但“全图即读”需要在更高缩放级别浏览。
2. **概念缺口**：上一轮固定参考集仍有 7 项缺少同篇干净概念（如 001 的 inverted PSCs、
   201 的 grain boundaries、250 的 colloidal nanocrystals）。
3. **类型与方向**：7,135 条类型冲突与 159 条方向待复核仍以“复核队列”形式存在；
   界面标注但不自动改写。证据缺行号 1,475 条，侧栏标注“定位缺失”。
4. **未做全量重抽**：摘要误删、失败块补抽、跨学科本体扩展、全量推断均按方案留待交付后。
5. **交付范围**：本轮验收是文件计数、端点完整性与定位案例，不代表全库语义准确率或召回率；
   下一轮应补充独立随机抽样评估，并与定向风险集分开报告。
